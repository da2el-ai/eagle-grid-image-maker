- 対応文書：[全体仕様書](./01_全体仕様書.md)／[技術検証事項](./03_技術検証事項.md)

## 0. モックアップ作成AIへの指示

> 添付の「Image Export Studio」スクリーンショットを**ビジュアルリファレンス**として、別製品 **Eagle Grid Image Maker** のデスクトップ用UIモックアップを作成する。スクリーンショットの3カラム構成、暗色配色、青色アクセント、余白感、入力コンポーネントのサイズ感を継承する。ただし機能は本書のものに置き換える。**右カラムの画像一覧を、グリッド画像プレビューにすることが最大の変更点**。現行採用機能のみを表示し、保留機能のボタンを先取りして追加しない。

### 成果物の優先度

1. 実際のアプリ画面に近い**高忠実度デスクトップモック**。
2. 中央カラムの設定カテゴリを切り替えた状態の画面差分。
3. 削除モード、再読み込み確認、XYプロット、複数ページ、出力警告の状態差分。
4. 見た目がよくても、**右上・右下の固定並びを変更しない**。

## 1. 画面全体の骨格

### 1.1 ベースとなる見た目

- ダークテーマ、グレー系の細い境界線、青系アクセント。
- 原則として、提供スクリーンショットの**約1144×785 px**を初回モックのキャンバス目安とする。これは画像の参照寸法であり、プラグインの必須固定寸法ではない。
- 左端は幅約80pxの**縦アイコンナビゲーション**。
- 中央は幅約320pxの**設定ペイン**。右が残り全幅の**プレビュー領域**。
- 上端にはアプリ名「Eagle Grid Image Maker」。スクリーンショット中の既存プリセット・保存／リネームボタンを移植しない。
- 右カラムは**上：サブ操作／中央：プレビュー／下：情報＋メイン操作**の3段。

### 1.2 全体のワイヤーフレーム

```text
┌───────────────────────────────────────────────────────────────────────────────────────────────┐
│ Eagle Grid Image Maker                                                                        │
├──────────┬────────────────────────────┬───────────────────────────────────────────────────────┤

│  ▦       │  グリッド                  ├───────────────────────────────────────────────────────┤
│          │  ────────────────────────  │                                                       │
│  ▧       │  横に並べる数  [ 4      ]  │                    グリッドタイトル                   │
│          │  配置方向      [右へ    ▾]  │              ┌────────┬────────┬────────┐           │
│  T       │  セル幅        [400] px    │              │        │        │        │           │
│          │  セル高さ      [400] px    │              │ image1 │ image2 │ image3 │           │
│  ◉       │                            │              ├────────┼────────┼────────┤           │
│          │                            │              │        │        │        │           │
│  ↓       │                            │              │ image4 │ image5 │ image6 │           │
│          │                            │              └────────┴────────┴────────┘           │
│          │                            │                                                       │

│          │                            │                                                       │
├──────────┴────────────────────────────┴───────────────────────────────────────────────────────┤
```

**重要**：下段はユーザー指定どおり、左に情報、右にメイン操作が並ぶ**基本1行レイアウト**。画面が狭い場合の省略・レスポンシブ挙動はモックアップ上の別案として示してよいが、標準状態の順序を変えない。

## 2. 左カラム：カテゴリアイコン

| 表示名称（提案） | アイコンの例 | 選択すると表示する設定 |
|---|---|---|
| グリッド | `layout-grid` | 横に並べる数・配置方向・セル幅・セル高さ |
| 画像 | `image` | 表示方法・向き・並び順 |
| テキスト | `type` | グリッドタイトル・XYプロット・フォント |
| 外観 | `palette` | 背景色・ギャップ・外周余白 |
| 書き出し | `download` | 出力形式・品質・出力サイズ／警告 |

- カテゴリ選択はアイコン主体、必要に応じて小さなラベルやツールチップを添える。
- 選択中のカテゴリは既存プラグイン同様、明度差と青いアクセントで示す。
- カテゴリ名／アイコンは**UI案**。機能そのものは確定仕様に準ずる。

## 3. 中央カラム：タブ別設定UI

下記の入力形式・初期値のうち、**確定値以外はモックアップ用の仮値**。AIは仮値を新規要件として扱ってはならない。

### 3.1 グリッド

```text
グリッド
────────────────────────────
横に並べる数     [ 4     ]      (1〜16)
配置方向         [左上→右 ▼]    (左上→右／左上→下)
セル幅           [ 400   ] px
セル高さ         [ 400   ] px
```

確定初期値はセル400×400のみ。「4列」「左上→右」は見本。

### 3.2 画像

```text
画像
────────────────────────────
表示方式         [ Cover | Contain ]
小画像を拡大     [ ON ]
向きを揃える     [回転しない ▾]
回転方向         [時計回り   ▾]
並び順           [ファイル名順 ▾]
順序             [ 昇順 | 降順 ]
```

- 並び順の選択肢は**選択順／ファイル名順／登録時刻順／手動順／ランダム**。
- 「ランダム」を選択すると1度だけシャッフル。**再シャッフルボタンは作らない**。
- ランダム順では昇順・降順コントロールを無効化する。

### 3.3 テキスト

```text
テキスト
────────────────────────────
タイトル          [                     ]
タイトルのフォント[システム標準        ▾]
タイトルのサイズ  [ 32 ] px

XYプロット        [ ON / OFF ]  ※表示UIは提案
横軸タイトル      [                     ]
縦軸タイトル      [                     ]
列ヘッダー        [ 個別項目を編集…    ]
行ヘッダー        [ 個別項目を編集…    ]
ヘッダーのフォント[システム標準        ▾]
ヘッダーのサイズ  [ 20 ] px
```

- タイトルは**改行不可**、文字高さ＋下余白**0.5em**。
- **列・行の個別ヘッダー**が中心機能。列1、列2…／行1、行2…の文字を個別入力可能なUIを示すこと。
- **横軸・縦軸タイトルも採用**。ただし軸ラベルの回転・余白などは未確定。
- 個別ヘッダー編集のUI方式は**未決定**。モックでは「編集ダイアログ案」または「中央ペインに展開するリスト案」を示してよい。
- 32px、20px、「XY ON/OFF」の具体UI方式は未確定のモック用仮値。

### 3.4 外観

```text
外観
────────────────────────────
背景色           [ ■ #FFFFFF ]
セル間ギャップ   [ 0 ] px
外周余白         [ 0 ] px
```

`#FFFFFF`と`0`は仮の初期値。**セル専用背景色・角丸・枠線・透明背景**は採用済みの設定ではないので、初期モックへ追加しない。

### 3.5 書き出し

```text
書き出し
────────────────────────────
形式             [ JPEG | PNG | WebP ]
品質             [ ─────●───── ] [ 90 ]  ※JPEG/WebPのみ

出力解像度       6400 × 6400 px
出力ページ数     3ページ
推定メモリ       （検証結果に応じて表示方法を設計）
[!] 形式変更でサイズ上限超過の場合は警告
```

- フォーマットは**JPEG / PNG / WebP**のみ。
- 品質スライダーはJPEG / WebPで有効、PNGは非表示／無効。
- **保存先フォルダ指定欄は作らない**。
- 出力解像度・ページ数は自動計算。上記の数値は仮表示。
- 書き出しファイル名の基本名を編集する欄は**未確定**のため、初回モックでは表示しなくてよい。

## 4. 右カラム上部：サブ操作（並び固定）

ユーザー指定の順序とグループ境界を厳守する。

```text
                              [再読み込みアイコン] [ゴミ箱アイコン] │ [Fitアイコン] [-] [+]
```

| 操作 | スタイル・動作 |
|---|---|
| 再読み込み | アイコン。クリック→確認ダイアログ→Eagle選択リストを取得 |
| ゴミ箱 | ON/OFFを持つトグル。ON時は青または警告色でアクティブ表示 |
| 縦の区切り | ゴミ箱とFitの間に薄いセパレーター |
| Fit | プレビュー全体を表示領域に収める |
| − | グリッド全体を縮小 |
| ＋ | グリッド全体を拡大 |

アイコンに説明ラベルを常設しない（ホバーツールチップは可）。サブ操作は全体として**右寄せ**。

## 5. 右カラム中央：グリッドプレビュー

- **設定変更を即時反映**する。
- 画像を縦横に並べたプレビュー。並び順・Cover/Contain・回転・テキスト・余白・ギャップを再現。
- 起動／ページ切り替え時はページ全体をFit表示し、任意にパンとズームが可能。
- プレビューに元画像の高精細な画素を表示する必要はない。Eagleのサムネイルだけ使用する。
- 操作：ドラッグ＝パン、ホイール＝ズーム、Ctrl/Cmd + ドラッグ＝セル並べ替え。
- ページ送りは**右カラム下部**に配置。プレビュー内に別のページナビを重複配置しない。
- **未選択・読み込み中・エラー・保存できない警告**の状態を視覚的に表現する。

### 5.1 XYプロットの表示例（ダミーデータ）

```text
                           グリッドタイトル
                              横軸タイトル
                    Header-A     Header-B     Header-C
      ┌───────────┬────────────┬────────────┬────────────┐
縦軸  │ Row-1     │  Image 1   │  Image 2   │  Image 3   │
タイトル├───────────┼────────────┼────────────┼────────────┤
      │ Row-2     │  Image 4   │  Image 5   │  Image 6   │
      └───────────┴────────────┴────────────┴────────────┘
```

- **個別ヘッダー**は列ごと・行ごとに異なる文字列。
- 行ヘッダー領域（左）の幅：`clamp(セル幅, テキスト幅, 100em)`相当、縦はセル高さ、中央揃え・文字右寄せ。
- 列ヘッダー領域（上）の幅：セル幅、高さ：`max(1em, 折り返したテキスト高さ)`、下寄せ・左右中央。
- 上図は関係だけを示す。軸タイトルの厳密な余白・向きは未決定。勝手に確定仕様として固定しない。

## 6. 右カラム下部：メイン操作＋情報（並び固定）

ユーザー指定の原文を保持したレイアウト：

```text
[◀][▶]  Page <現Page番号> / <総Page番号> | <画像枚数>枚 | <現在の並び順> |        [グリッドをクリア] [キャンセル] [グリッド保存]
```

- 左から**前後ページボタン → Page n / N → 画像総数 → 現在の並び順**。
- 右端に**グリッドをクリア → キャンセル → グリッド保存**の3ボタン。
- `グリッド保存`は鮮明な青の主ボタン、他のボタンは控えめ。
- 1ページのとき前後矢印は無効。最大32ページ。
- 画像ゼロ時の保存無効化は**UI提案**。確定ルールは技術検証後に詰める。
- **[未決定]** `Page n`をクリックして直接ページ番号へ移動する仕組みは初期モックで不要。
- `キャンセル`は画面を閉じる操作を想定するが、詳細動作は未決定。

## 7. ダイアログ・画面状態（モックに含める）

| 状態 | 最低限の見せ方 | 確定度 |
|---|---|---|
| 標準状態 | グリッド・上部ツール・下部情報バー | [確定] |
| テキスト／XYプロット | 列・行ヘッダーと軸タイトルをプレビュー | [確定] |
| 再読み込み確認 | 現在のリストへ再取得を適用する確認ダイアログ | [確定] |
| 削除モード | ゴミ箱のアクティブ状態＋セルを押した後の確認ダイアログ | [確定] |
| 複数ページ | Page n/N、前後移動可否、画像総数 | [確定] |
| ランダム順 | フッターに「ランダム」、再抽選ボタンはない | [確定] |
| 上限警告 | 出力形式の変更やサイズ超過を警告 | [確定：警告] |
| クリア確認 | 全削除の確認ダイアログ | [提案：未決定] |
| 空／読込中／画像不正 | プレースホルダーと状態表示 | [実装上の必要事項、詳細未決定] |

## 8. モックアップでは表示しない機能

初期版に混ぜてはいけない保留機能：

- Shift + ドラッグのセル内位置調整UI／Shift + ホイールのセル内ズームUI。
- ホバー左上／右上の回転アイコン、右下のリセットアイコン。
- 常設「編集モード」ボタン（**廃止済み**）。
- 画像名／連番のセル内表示、Undo/Redo、空白セル、プリセット、クリップボードコピー、Eagleへの書き戻し。

## 9. モックアップの受け入れ条件

- [ ] 参照スクリーンショットと同系統のダークUI、3カラムである。
- [ ] 左＝カテゴリ、中央＝設定、右＝**グリッド**（一覧テーブルではない）。
- [ ] 右上の順序は `再読み込み → ゴミ箱 | Fit → − → ＋`、全体右寄せ。
- [ ] 右下は左側情報、右側3操作ボタンの基本1行、順序厳守。
- [ ] 画像／テキスト／外観／書き出しの主要設定が画面上で確認できる。
- [ ] XYプロットの**個別行列ヘッダー＋軸タイトル**を表示できる。
- [ ] サムネイルのFit、パン、ズーム、並べ替えをUIで表現できる。
- [ ] 保留機能を実装済みUIと混同していない。
- [ ] 仮の数値（4列、32px、品質90等）を確定仕様に見せていない。
